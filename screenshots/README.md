# Screenshots

Add your app screenshots here with these filenames so the main README picks them up automatically:

- `login.png` — the sign-in / register screen
- `chat.png` — the "Ask AI" chat screen
- `documents.png` — the document library / upload screen
- `history.png` — the chat history screen

Recommended: PNG, ~1280px wide, light compression so the repo doesn't bloat.
